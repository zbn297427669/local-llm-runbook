# Strata · 16 GB 显存跑 1770 亿参数模型

**一台 16 GB 显存的消费级显卡，能不能承担日常的本地推理工作？**

这个项目记录了一套能用的配置：从「跑起来了」到「调到头」，怎么装、怎么调、
每一步的数字是多少。所有数字都带出处，所有结论都标了适用边界。

> 仓库级说明、其它项目见 [`../README.md`](../README.md)。

---

## 结果

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 显存 | **16 GB** | RTX 4080 |
| 模型总参数 | **1770 亿** | Qwen3.8-Flash-Next，MoE，512 个专家，每 token 激活 10 个 |
| 模型文件 | **73 GB** | iq2_xs 量化，装不进显存，按需从内存取 |
| 上下文 | **256K** | |
| 短请求生成 | **约 90 tok/s** | 短请求，不是长上下文 |
| 读图耗时 | **311.7 s → 57.4 s** | 同一任务，单次样本 |

> 这三个速度数字都是**单次样本**，不是统计值。单机单卡，不推广为通用结论。

## 路径与硬件约定

- 文档里的 `$env:STRATA_HOME`（cmd 批处理里写 `%STRATA_HOME%`）指 **Strata 安装目录**，
  也就是含 `terminal\`、`models\`、`patches\` 的那一层。仓库里不写死盘符和用户名，
  你装在哪就指到哪，例如 `D:\llm\Strata`。跑 `scripts/` 里的脚本前先设一次；
  不设会明确报错，不会按某个默认盘符瞎猜。
- `%LOCALAPPDATA%` / `%APPDATA%` 是 Windows 环境变量，`<user>` 是用户名占位符。
- 硬件是 RTX 4080 16 GB、i7-13700K、64 GB DDR5，**参考配置**。换硬件请重测，
  参数结论绑定这套硬件。

## 三条读法

**只想把它跑起来** → 从 `RESTORE.md` 开始，按第 2 节的目录布局走，跑不起来看第 8 节的排查表。

**已经跑起来，觉得慢** → `skills/strata-tune/SKILL.md` + `docs/调优方法论与skill设计.md`。注意：这套方法的核心不是参数表，是**先确认你要优化的是哪个指标**。

**不关心模型，只关心方法** → [`../method/ask-the-agent/`](../method/ask-the-agent/)。真正的结论在那里：

> 同一个 Agent，读引擎日志反推参数、把一个假设跑完量出数字，都做得很好。
> 它的盲点不在做事，而在**结论**——工具给了它一个答案，它没有追问这个答案成不成立。
> 而人能问的，正好是它看不见的：**「你试过哪些？」**

## 边界

诚实地说清楚哪些没有验过：

- **单机单卡**，一台 4080。没有做跨机型、跨引擎的系统对照。
- **速度数字是单次样本**，不是多次平均。
- **Agent 的构成要说清**：外壳是 Claude Code，模型是**中转站的 DeepSeek**，经 Claude Code Router 接入。中转站不完全等于官方 API——可能限流、可能改系统提示，量化和版本也不一定与官方一致。所以这里所有关于「Agent 盲点」的记录，只针对**这一次的具体组合**。
- **没有做跨模型对照**：同一个任务、同一套 harness、换成别的模型（包括官方 DeepSeek、Claude、其他模型）会不会更容易主动审自己的结论，这里**没有数据**。这是这个项目下一步最想补的实验，见 [`../method/ask-the-agent/`](../method/ask-the-agent/)。
- USB 小屏输出只记录了观察窗口，样本太少、没有对照，**不下结论**。
- 官方调优器的结论只覆盖它测过的范围，别当成定论；换配置或换机器要自己量。
