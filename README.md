# local-llm-runbook · 本地大模型运行手册

一台机器上，把本地大模型跑到「能日常用」的完整记录：部署、踩坑、调优、验证，
以及被自己推翻的结论。

仓库按项目分目录，**每个项目自包含**：一个项目里的文档、证据、脚本互不引用其它项目。

---

## 项目

| 目录 | 引擎 / 模型 | 一句话 |
| --- | --- | --- |
| [`strata/`](strata/) | Strata + Qwen3.8-Flash-Next | 16 GB 显存的 RTX 4080 跑 1770 亿参数、256K 上下文，短请求约 90 tok/s（单次样本） |

## 与具体项目无关的部分

| 目录 | 内容 |
| --- | --- |
| [`method/ask-the-agent/`](method/ask-the-agent/) | 追问清单：Agent 最容易停下来的四个地方，以及该问的那一句 |

---

## 一个项目目录里有什么

`strata/` 就是模板：

| 文件 / 目录 | 作用 |
| --- | --- |
| `README.md` | 这个项目在做什么、结论、适用边界 |
| `RESTORE.md` | 从零把环境跑起来的可执行手册 |
| `docs/` | 过程记录、选型比对、方法论 |
| `evidence/` | 原始日志摘录，数字可逐字核对 |
| `scripts/` | 探测与 bench 脚本 |
| `patches/` | 对引擎的补丁 |
| `skills/` | 可直接喂给 Agent 的 Skill |
| `cases/` | 可复现的对照实验 |

再加一个项目（换引擎、换机器、换模型）时：新建同级目录，按上面的结构放自己的东西，
在本文件「项目」表里加一行即可。**项目之间不做相对引用**，路径只出现在自己的目录里。

## 约定

- 机器特定路径不写死：安装目录用环境变量表示（Strata 项目用 `$env:STRATA_HOME`），
  `<user>` 是用户名占位符，具体见各项目 README。
- 硬件与数字都是参考值，换硬件请重测，别照抄参数。
